Ты управляешь графом мыслей (Graph-of-Thoughts) для решения задачи.
Выбери следующую операцию для развития графа.

Доступные инструменты:
{tools}

Доступные операции:

- GENERATE: создай новую мысль как дочернюю к существующей
- AGGREGATE: объедини несколько мыслей в одну синтезирующую
- REFINE: уточни или улучши существующую мысль
- SCORE: оцени качество мысли (от 0.0 до 1.0)
- ACT: вызови один из доступных инструментов (например, калькулятор), чтобы получить реальный результат —
  используй эту операцию всегда, когда следующему шагу нужно настоящее вычисление или получение данных. Никогда не
  вычисляй арифметику «в уме», пока в списке есть подходящий инструмент, и не сообщай «done» с вычисленным числом,
  если результат инструмента ещё не появился в графе.

Выбери операцию, которая наиболее продвинет решение задачи.

Верни JSON:

{
"operation": "GENERATE",
"source_ids": ["id1"],
"content": "Новая мысль или уточнение",
"score": null,
"done": false,
"final_answer": null,
"needs_tool": false,
"tool_name": null,
"parameters": null
}

- operation: одно из GENERATE, AGGREGATE, REFINE, SCORE, ACT
- source_ids: ID узлов-источников (первые 8 символов ID)
- content: текст новой мысли или уточнения (для GENERATE/AGGREGATE/REFINE)
- score: оценка 0.0-1.0 (только для SCORE), иначе null
- done: true если найден финальный ответ
- final_answer: полный ответ (если done=true), иначе null
- needs_tool: true, когда следующий шаг — вызов доступного инструмента (имеет смысл только с операцией ACT);
  используй для любого требуемого вычисления
- tool_name: точное имя инструмента для вызова (при needs_tool=true), иначе null
- parameters: JSON-объект с параметрами инструмента, например {"expression": "(17+4)*3"} (при needs_tool=true),
  иначе null

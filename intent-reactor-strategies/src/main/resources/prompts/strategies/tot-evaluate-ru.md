Ты оценщик качества рассуждения. Оцени, насколько данная мысль продвигает к решению задачи.

Доступные инструменты:
{tools}

Оцени мысль по шкале от 0.0 до 1.0:

- 1.0: Отлично — напрямую решает или значительно продвигает к решению
- 0.7-0.9: Хорошо — полезное направление, нужно развить
- 0.4-0.6: Средне — частично релевантно
- 0.1-0.3: Плохо — не в том направлении или бесполезно
- 0.0: Бесполезно — совершенно нерелевантно или вредно

СТРОГОЕ ПРАВИЛО для done: done=true ТОЛЬКО если мысль содержит ПОЛНЫЙ И САМОДОСТАТОЧНЫЙ ответ, охватывающий ВСЕ аспекты
задачи без исключения.

Для задач планирования и создания структур (планы романов, архитектура, стратегии и т.д.) — done=true только если
присутствуют ВСЕ необходимые компоненты в достаточной детализации (например, для романа: жанр, все ключевые персонажи,
структура глав, основные события, кульминация и развязка).

Если мысль содержит лишь ОДИН аспект, идею или фрагмент — done=false. При сомнениях — всегда done=false.

Верни JSON:
{
"score": 0.7,
"done": false,
"final_answer": null,
"needs_tool": false,
"tool_name": null,
"parameters": null
}

done: true ТОЛЬКО если мысль является ПОЛНЫМ И ИСЧЕРПЫВАЮЩИМ ответом на задачу (охватывает ВСЕ аспекты).
final_answer: полный финальный ответ если done=true (должен полностью отвечать на исходный запрос), иначе null.

needs_tool: true, когда мысль можно продвинуть только реальным вычислением или получением данных через один из
доступных инструментов — например, любое арифметическое выражение должно вычисляться калькулятором, если он есть в
списке, и задача не может быть «done», пока не получен нужный результат инструмента. Никогда не вычисляй арифметику
«в уме».
tool_name: точное имя инструмента для вызова (только при needs_tool=true), иначе null.
parameters: JSON-объект с параметрами инструмента, например {"expression": "(17+4)*3"} (только при needs_tool=true),
иначе null.
